#OBSIDIAN PULSE⌚
An interactive virtual smartwatch which displays information on how health data is analyzed and displayed.

Project Overview

OBSIDIAN PULSE is an interactive virtual smartwatch designed to demonstrate the technology and data processing behind modern wearable devices
Smartwatches can analyze data to determine for example Heart Beat (measured in BPM) and SpO2. Despite this the mechanisms which enable this are hidden beyond the glass and do not detail hoe data is analyzed.
OBSIDIAN PULLSE is designed to overcome this issue by offering through which wearable data and its visualization can be showcased.

✨Key Features
Virtual Smartwatch Interface: An interactive smartwatch inspired dashboard.
Heart Rate Monitoring: Visual representation of BPM readings.
SpO2 Monitoring: Displays blood Oxygen saturation readings.
Data Visualization: Graphical representation of sensor related data.
Interactive Dashboard: Dynamic Interface with real time style updates.
Sensor Status Indicators: Visual Indicators for sensor activity and status.
Responsive Design: Designed to provide an accessible experience across screen sizes.

🛠️Technology Stack
[Stimulated Sensors] - Python Flask, [Interactive Dashboard] - HTML, CSS, JavaScript.
