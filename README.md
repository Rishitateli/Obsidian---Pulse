OBSIDIAN PULSE

Virtual Smartwatch | Understanding the Technology Behind Wearable Devices

🚀 About the Project

OBSIDIAN PULSE is an interactive virtual smartwatch designed to demonstrate the technology and data processing behind modern wearable devices.

Smartwatches provide users with health metrics such as Heart Rate (BPM) and SpO₂, but most users only see the final readings without understanding the technology behind them.

Our project aims to make wearable technology more transparent, interactive, and understandable through a virtual smartwatch interface and visual data representation.

🎯 Problem Statement

Millions of people rely on smartwatches for health and fitness tracking. However, the underlying technology often operates as a black box, providing readings without explaining how the data is processed or interpreted.

OBSIDIAN PULSE aims to bridge this gap by providing an interactive platform that demonstrates wearable sensor data and its visualization.

✨ Key Features

- Virtual Smartwatch Interface: An interactive smartwatch-inspired dashboard.
- Heart Rate Monitoring: Visual representation of BPM readings.
- SpO₂ Monitoring: Displays blood oxygen saturation readings.
- Data Visualization: Graphical representation of sensor-related data.
- Interactive Dashboard: Dynamic interface with real-time-style updates.
- Sensor Status Indicators: Visual indicators for sensor activity and status.
- Responsive Design: Designed to provide an accessible experience across screen sizes.
